# Rockio Clothing POS

A mobile-first Point of Sale system built for a hybrid retail + tattoo studio.

## Features
- 🧾 Product sales with payment tracking (Cash / Card)
- 📦 Inventory stock management (Admin protected)
- 🔐 Admin PIN protection for sensitive actions
- 🖋 Tattoo booking management (schedule, pricing, status)
- 📊 Daily sales reports and summaries
- 📱 Optimized for Android & iOS (Expo / React Native)

## Tech Stack
- React Native (Expo)
- TypeScript
- SQLite (offline-first)
- Expo Router
- Custom admin access control

## Business Use Case
Designed specifically for Rockio Clothing to:
- Prevent stock manipulation
- Track daily revenue accurately
- Manage tattoo bookings alongside retail sales
- Operate fully offline on mobile devices
